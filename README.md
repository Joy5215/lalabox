# LALABOX · 哼两句，就成歌

对着麦克风哼 8 拍，浏览器自动听音高、找调、配和弦、编鼓组与贝斯，几秒产出一首带伴奏的小 demo。
零乐理、零注册、不上传声音，全部计算在本地完成（Toy 云存储与分享除外）。

## 运行

**本地预览**：直接双击 `index.html`。
Toy SDK 脚本在没有 `file://` 权限或离线时会加载失败，此时自动进入本地模式：
麦克风走 `getUserMedia`，作品存 `localStorage`，分享改为展示二维码占位。

**必须以 HTTP 打开的情况**：如果浏览器禁止 `file://` 访问麦克风，用任意静态服务器：

```bash
npx serve .        # 或
python -m http.server 8080
```

**上传到 Toy**：把整个目录作为 Toy 资源上传，入口为仓库根目录的 `index.html`。

## 目录结构

```
lalabox/
├── index.html            页面结构（无内联样式与脚本）
├── css/
│   ├── base.css          设计变量、重置、背景光晕
│   ├── components.css    按钮 / 麦克风 / 面板 / 浮层 / 提示条
│   └── layout.css        应用骨架、舞台、控制坞、断点
├── js/
│   ├── core/utils.js     工具函数与全局常量（LALA.util / LALA.C）
│   ├── core/bridge.js    Toy 平台适配层（LALA.Bridge）
│   ├── music/arrange.js  和弦与四风格编曲（LALA.ARRANGE）
│   ├── music/codec.js    base36 紧凑编解码（LALA.CODEC）
│   ├── music/analyze.js  YIN 音高检测与音符化（LALA.ANALYZE）
│   ├── music/compose.js  调式识别、音阶吸附、和弦选优（LALA.COMPOSE）
│   ├── audio/engine.js   Web Audio 合成与排程（LALA.ENG）
│   ├── ui/draw.js        canvas 绘制（LALA.DRAW）
│   └── app.js            状态机与交互
└── tools/smoke-test.js   纯逻辑模块冒烟测试
```

脚本通过 `window.LALA` 命名空间串联，**加载顺序不能调换**（见 `index.html` 底部）。
所有模块都是 IIFE，不污染全局。

## 自检

```bash
node tools/smoke-test.js
```

覆盖：成曲结果合法性、编解码往返一致、非法输入拒绝、四种风格均可编曲、事件按拍排序。

## 交互流程

1. 点大麦克风按钮 → 申请麦克风 → 4 拍预备（「哒」×4）→ 8 拍演唱 → 自动结束。
2. 分析阶段分四句轮播文案，期间界面不阻塞。
3. 结果页自动播放；可换 流行 / 电子 / Lo-fi / 摇滚 即时重编；可「存下来」「分享」「海报」。
4. 分享链接形如 `index.html?s=<code>`，打开即还原同一首（不自动播放，需点一下）。

## 平台能力与降级

| 场景 | 行为 |
| --- | --- |
| App 内 | `toy.requestMicrophone` / `stopMedia`，云存储 + 本地双写，`share` 拉起分享面板，`saveImageToAlbum` 存相册 |
| Web 端 | `share` 不可用 → 展示 `getQrCode` 二维码；`saveImageToAlbum` 不可用 → `<a download>` 下载 |
| 未登录 | 云存储报错 → 只写 `localStorage`，提示「已存本机」 |
| 接口限流 307044 | 指数退避重试 3 次，仍失败则写本机 |
| 无 SDK / 脚本加载失败 | 全量本地模式，功能不减 |
| 麦克风被拒 | 中文提示 + 「听听示例」兜底旋律 |
| 有效音符 < 3 | 判定「没听清」，回到首页提示重录 |

数据上限：云存储单值 ≤1024 字节，因此 `Song` 用 base36 编码（16 音约 70 字符）。
URL 参数解码前会校验长度 ≤512、字符集 `[0-9a-z]`、音数 ≤64、音高 36–99，非法直接丢弃。

## 录屏分镜（约 60 秒）

| 时间 | 画面 | 台词 |
| --- | --- | --- |
| 0–6s | 首页大按钮呼吸动画 | 「我完全不懂乐理，但我想写歌。」 |
| 6–12s | 点击，四拍节拍灯依次点亮 | 「它先给我四拍，跟着哒哒哒哒哼就行。」 |
| 12–22s | 环形频谱随声音起伏，电平条跳动 | 「随便哼，跑调也没关系。」 |
| 22–30s | 分析文案轮播 + 进度条 | 「现在它在听我的音高、找调、配和弦。」 |
| 30–42s | 音高轨迹生长 + 四轨卷帘亮起 | 「鼓、贝斯、和弦，全自动配好了。」 |
| 42–52s | 依次点四个风格 chip | 「同一段哼唱，换四种曲风。」 |
| 52–60s | 生成海报，二维码出现在角落 | 「扫码就能听我这首歌。」 |

## 已知限制

- 固定 96 BPM 与 8 拍长度，未做自由节拍量化。
- 音高检测针对人声哼唱（70–1100Hz），乐器独奏可能需要先降八度。
- 单次分析约 5 秒音频，低端机可能出现 1–2 秒处理等待（有进度反馈）。
