# LALABOX · 哼两句，就成歌

对着麦克风哼 8 拍，浏览器自动听音高、找调、配和弦、编鼓组与贝斯，几秒产出一首小 demo。
零乐理、零注册、不上传声音，全部本地计算（Toy 云存储与分享除外）。

## 运行

- **本地预览**：双击 `index.html`。Toy SDK 加载失败会自动进本地模式（麦克风走
  `getUserMedia`，作品存 `localStorage`，分享降级成二维码占位）。
- **需要 HTTP 时**：`node tools/serve.js`（等价 `npx serve .` 或 `python -m http.server 8080`）。
- **手机真机（首选）**：`node tools/tunnel.js`。一条命令起本地服务 + cloudflared 隧道，
  控制台会打印 `https://xxx.trycloudflare.com/`，手机直接打开这个地址。https 是安全上下文，
  麦克风权限正常；地址每次启动都变，用完 `Ctrl+C`（会同时关掉服务与隧道）。
- **没网 / 装不了 cloudflared 时**：`node tools/serve.js` 后 `adb reverse tcp:8080 tcp:8080`，
  手机开 `http://localhost:8080`。注意**电脑重启后 reverse 规则一定失效**，每次开机都要重设。
  原理与排障见 [DEV-NOTES.md](DEV-NOTES.md)。

## 发布

```bash
node tools/make-assets.js                      # 图标与封面，首次或改视觉时
node tools/pack.js                             # 产出 dist/
toy update 55182818016256 dist --json          # 只出预览
toy update 55182818016256 dist --json --yes    # 提交审核
```

测试用 Toy `lalabox-test`（id `55182818016256`）。`create` 必须带 `--poster`；
`update` 必须显式传 id；slug 发布后不可改。

## 同步到 GitHub

仓库：`https://github.com/Joy5215/lalabox`。SSH 走 `ssh.github.com:443`（部分网络封了 22 端口）。

- **首次推送**（只需一次）：`origin` 已配好，`git push -u origin main` 即可。
  前提：本机 SSH 公钥已加到 GitHub（Settings → SSH and GPG keys）。
- **之后一键同步**：`npm run sync`（= `node tools/git-sync.js`），
  依次 `pull --rebase --autostash` → 有改动才提交 → `push`；可带自定义提交信息：
  `npm run sync -- "feat: xxx"`。遇到 rebase 冲突会停下并提示手动处理，不会 force push。

## 自检

```bash
node tools/smoke-test.js
```

覆盖成曲合法性、编解码往返（含 v9 多段与 v1–v8 老链接）、非法输入拒绝、
生成器契约（同种子可复现 / 换种子会变 / 情绪真的改变密度）、片段归一化与静音、音色目录自洽。
`node tools/e2e.js` 会拉起浏览器真跑一遍：录音 → 编曲时间线（拖拽裁剪 / 分割 / 定位起播）→ 加入乐队。

常用脚本已收进 `package.json`，可用 npm 跑：`npm test` / `npm run e2e` / `npm run serve` /
`npm run tunnel` / `npm run pack` / `npm run push`。

## 交互

1. 点麦克风 → 4 拍预备 → 8 拍演唱 → 自动结束。
   不想唱也行：麦克风下方有「输入简谱」（1-7 写音阶，0 是停顿，一个数字一拍，最多 16 拍）
   和「随机旋律」（按感觉选：一次给 3 段不同心情的候选，一段小调、两段大调，
   疏密和音区也拉开；点一段先试听、满意再点「就用这段」，不满意「换一批」）。
2. 分析时文案轮播，界面不阻塞。
3. 结果页先选「用什么声音唱」：原声 / 钢琴 / 木吉他 / 古筝 / 柔和合成 / 笛子 / 8-bit。
   此时**只有这一条**主音，没有伴奏。
4. 「你的乐队」标题右侧是圆形 ＋ 按钮，点开是同一个面板：最上面一张清单列**所有已经在响的**
   （乐器 / 人声 / 氛围混排），下面的「添加 · 示范」区用 **乐器 / 氛围 / 示范** 三个页签切换：
   - **已经加上的**：一件一行，右边滑音量、点 ✕ 删掉这一轨。点行名展开换**曲调**
     （晴天 / 深夜 / 温柔 / 下雨 / 热血 / 复古 / 派对 / 清晨）；换曲调会同时重抽它的律动，
     只让这一件响，方便对比。同一层可以叠多件，每件各有一套曲调与种子。
     列表第一行的**旋律轨就是当初选的主音**（钢琴 / 木吉他 / 我的原声…），按它实际音色命名，
     不再叫「主旋律」；要换这一轨的音色，回到结果页的主音色面板挑一个即可
   - **编曲（全屏时间线）**：点行内「编曲」进剪映式的多轨界面——每件乐器 / 人声 / 氛围各占一条轨，
     旋律轨也是普通一条（不再只读）。片段可以拖着整段平移（**上下拖到别的轨就是搬过去**）、拖两端裁剪、
     在空白处横向拖一下新建一段、在播放头处分割、单独删掉某一段；全部吸附半拍，
     拖动只改预览、松手才重排声音。**点空白处只选轨、不新建**——删掉一段后顺手点一下，
     不会又长出一段来；要新建就横向拖出长度。
     拖到所有轨道下面的空白（拖动时会亮一条虚线的「＋ 新轨」）松手，就用同一件乐器另起一轨，
     只放搬过去的那一段；原轨的最后一段被搬走时，那条空轨会收起。
     点任意一段（连它上下的空白一起算）就选中它；轨道头点名字选轨，右下角小喇叭静音、✕ 整轨删除
   - **轨道静音**：轨道头右下角的小喇叭一点就静音（点亮 + 斜杠，整行压暗），底栏「静音这一轨 /
     这一轨出声」是同一个开关，不用去角落里找。静音只在这台设备上生效、不进分享码；
     和片段级静音分开管：**轨道静音 = 整条轨暂时不出声**，片段静音只关那一段
   - **片段自己的动作**（底部操作条）：`片段静音` 只让这一段不出声（斜纹标记，只在这台设备上，
     不进分享码）；`复制` / `剪切` 之后再点一条轨道 `粘贴`，粘在播放头后面第一个放得下的空位。
     旁边还有 ± 半拍 / ± 1 拍精修起止、一键「整段」，以及「整段」后面的 ← → 把这一段原样前后挪
     （长度不变，被邻段与 0~16 拍夹住），再加这一层的律动（慢一半 / 标准 / 快一倍）和整首升降半音
   - **三种试听别混**：`循环这段` 只循环当前这一个片段——循环长度就是这一段，播放头在段内打转；
     `整轨循环` 是整条音轨按 4 小节整圈循环，它所有的片段照常进出，用来听这一轨在整首里的样子
     （从第一段开头起播，片段之间的空档会真的没声）；`这段全部` 的循环窗口也是这一段，
     但**所有没静音的轨一起响**，用来听这一段配器合不合。三个都在底栏，正在响的那个会变成「停止」，
     再点一次即停；点整队播放也会接管
   - **哪一段在发声**：播放时片段右上角会亮一个小喇叭，底栏同步显示「正在响 8.0–12.0 拍」；
     走到两段之间的空档会变成「这一段是空档，没有声音」。静音的轨 / 静音段不会亮；
     `循环这段` / `整轨循环` 只亮试听的那一条轨，`这段全部` 与整队播放一样，谁在响就亮谁
   - **播放头**：时间尺上点一下或拖动定位，播放中定位立刻从新拍位重播，暂停后位置留着；
     再点播放就从那里继续。四个小节与 16 拍都标了刻度
   - **加入前也能编曲**：选完音色先响一版，点试听卡右上角的「编曲」，候选会作为一条
     「试听中」的临时轨出现在最下面，区间与律动调好再点「加入乐队」，参数原样带进去
   - **添加乐器**：默认全部收起。点家族展开，并先响一件代表音色；再点具体音色换着听。
     试听只出声、不进乐队，要加的时候点下面的「加入乐队」
   乐器可以任意叠加（钢琴 + 吉他 + 鼓 + 手鼓都行），每件在面板里单独调音量，默认 0.8。
   - **氛围页签**：雨声 / 篝火 / 溪流 / 蝉鸣 / 竹林 / 夜晚虫鸣 / 海浪 / 风声八种环境音，
     程序实时合成、不用音频素材。可以叠多条（雨声 + 篝火一起铺底），每条单独调音量、默认 0.6；
     氛围没有曲调与「换一版」，随整首一直响、不跟着 4 小节重来，切页签不会丢已加的
   氛围也进分享码，别人打开链接能听到同样的组合（合成配方在本地跑，不传音频）。
   - **示范页签**：两排现成的东西，点一下就能听：
     - **常用和弦走向** 1-6-4-5 / 1-5-6-4 / 6-4-1-5 / 4-5-3-6 / 2-5-1-6 / 1-4-5-1，
       卡片上按当前调写出实际和弦（C→Am→F→G 这种），点一条整支乐队立刻换掉，当前用的那条会高亮；
       乐队里还没有和音乐器时，会顺手加一层钢琴，保证点了就听得到
     - **底色**：雨夜（雨 + 虫鸣）、炉边（火 + 风）、溪畔（溪 + 竹林）、海边（浪 + 蝉），
       点一下整组叠上去，音量按「主铺底 + 点缀」配好，进乐队后仍可单独调；已在铺底的会标出来
   全局的「整队换一版」本轮下线，等另行设计。
5. 可存下来 / 分享 / 海报。分享链接形如 `index.html?s=<code>`，打开需点一下播放。

## 平台与降级

| 场景 | 行为 |
| --- | --- |
| App 内 | `toy.requestMicrophone`、云存储 + 本地双写、`share` 拉起面板、存相册 |
| Web 端 | `share` 不可用 → 二维码；存相册不可用 → `<a download>` |
| 未登录 / 无 SDK | 只写 `localStorage`，功能不减 |
| 限流 307044 | 退避重试 3 次，仍失败写本机 |
| 麦克风被拒 | 中文提示 + 「听听示例」兜底 |
| 有效音符 < 3 | 判定没听清，回首页重录 |

云存储单值 ≤1024 字节，`Song` 用 base36（16 音约 90 字符，满编 12 件约 190，每件 8 段约 400）。
URL 解码前校验长度 ≤768、字符集 `[0-9a-z]`、音数 ≤64、音高 36–99；每件最多 8 段、整串最多 32 段。

## 已知限制

- 固定 96 BPM、8 拍，未做自由节拍量化。伴奏循环 4 小节（16 拍），8 拍乐句在后两小节原样重复一次。
- 音高检测约 55–900Hz，70Hz 以下不稳。
- 单次分析约 5 秒音频，低端机可能等 1–2 秒。
- 同音重复（中间没停顿）会被并成一个音，因为没做起音检测。
- 乐器清单与每件的曲调、种子都进分享码（codec v5）；老链接（v1–v4）仍能解，
  v4 及更早的乐器没有自己的曲调 / 种子，按 `song.mood` / `song.seeds` 回落。
- 主音色（原声 / 钢琴 / 木吉他…）仍不编码，分享出去默认是合成音色。
- 氛围层跟乐器一样进 `band` 与分享码（曲调 / 种子写固定占位）；
  声音是现场噪声合成的，不传音频，不同设备的音色会有细微差别。
- 多段片段与这一层的律动倍率进分享码（codec v9，每件 11 位基础 + 段数 + 每段两位）；
  v8 及更早的链接解出来是单段或整段、标准律动。片段只在 16 拍循环内，不支持把歌拉长。
- 整轨静音与片段静音都只是本机试听用，不进分享码；别人打开链接听到的是完整编曲。
- 伴奏是规则生成的，保证对拍、在和弦内、符合情绪，但不会写出有记忆点的乐句。
